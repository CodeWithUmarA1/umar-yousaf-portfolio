Architecture Note

Codebase Structure & shadcn/ui Component Setup

Target: /components/ui/kinetic-grid.tsx
01. Why /components/ui Matters

shadcn/ui CLI conventions designate /components/ui exclusively for foundational primitives and design atomic blocks. Separating them from app-level or domain components guarantees predictable imports, automated CLI upgrades, and clear mental models.

02. Setup with shadcn CLI & Tailwind

In a fresh React/Next.js TypeScript setup, run: npx shadcn@latest init Configure default style variables, paths (@/components), and utility helpers (@/lib/utils).

03. Live Canvas Integration

This portfolio runs the exact interactive math of the KineticGrid: bell-curve cursor warp, proximity edge-pinning, and dynamic click ripples rendered at 60 FPS directly on the canvas background.
